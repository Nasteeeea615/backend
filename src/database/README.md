# Database Management

## Структура

```
database/
├── migrations/     # SQL миграции для создания схемы
├── seeds/          # Тестовые данные для разработки
├── migrate.ts      # Скрипт запуска миграций
├── seed.ts         # Скрипт запуска seeds
└── reset.ts        # Скрипт сброса базы данных
```

## Команды

### Создание базы данных

Сначала создайте базу данных PostgreSQL:

```sql
CREATE DATABASE septik_service;
```

### Запуск миграций

```bash
npm run migrate
```

Создает все таблицы и индексы.

### Заполнение тестовыми данными

```bash
npm run seed
```

Добавляет тестовых пользователей, заказы и платежи.

### Полная настройка базы данных

```bash
npm run db:setup
```

Запускает миграции и seeds.

### Сброс базы данных

```bash
npm run db:reset
```

Удаляет все таблицы (используйте осторожно!).

### Пересоздание базы данных

```bash
npm run db:refresh
```

Сбрасывает и заново создает базу данных с тестовыми данными.

## Схема базы данных

### Таблицы

1. **users** - пользователи системы
2. **client_profiles** - профили клиентов
3. **executor_profiles** - профили исполнителей
4. **orders** - заказы
5. **payments** - платежи
6. **tickets** - тикеты поддержки
7. **messages** - сообщения в тикетах
8. **notifications** - уведомления

### Тестовые данные

После запуска seeds будут созданы:

- 1 администратор
- 2 клиента с профилями
- 3 исполнителя с профилями
- 3 тестовых заказа (завершенный, в процессе, ожидающий)
- 1 тестовый платеж
